# 2026-10-20

### [Feature] Notes: `/notes` and the first note on the new CDN endpoint

- **Files:** `frontend/content/notes/new-office-js-cdn-endpoint.md`, `frontend/lib/notes.js`, `frontend/app/notes/page.js`, `frontend/app/notes/[slug]/page.js`, `frontend/app/notes/[slug]/opengraph-image.js`, `frontend/app/layout.js`, `frontend/app/sitemap.js`, `frontend/app/llms.txt/route.js`, `frontend/app/globals.css`, `frontend/package.json`, `docs/architecture/frontend.md`, `docs/architecture/seo.md`
- **Why:** a place for write-ups about what we see on the CDN; the first one explains how `officeapis.public.onecdn.static.microsoft` differs from `appsforoffice.microsoft.com`.
- **What:** notes are Markdown files with front matter (`title`, `description`, `date`, optional `seoTitle`, `updated`, `keywords`, `checked`), rendered at build time with `marked`; a `<!-- subscribe: … -->` line places the subscribe form. `/notes` lists them; each note has its own Open Graph image, article metadata and JSON-LD `TechArticle`. Notes are in the nav, the footer, the sitemap and `llms.txt`. The first note was checked against the loader and host files: `data-enable-trusted-types` turns on only with `"1"`, and with the security defaults on, function commands are looked up only among `Office.actions.associate` handlers. On phones the nav badge shows only its dot so the links fit one line.
