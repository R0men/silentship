# 2026-10-23

### [Bug Fix] Home page could miss a release the RSS feed already had

- **Files:** `backend/src/web/live.js`, `backend/src/web/queries.js`, `backend/src/web/server.js`,
  `frontend/app/page.js`, `frontend/components/Live.js`, `backend/test/home.test.js`
- **Why:** live-snapshot checks ran every 5 s without waiting for each other: a slow build started before a
  crawl wrote its data could finish last and stay until the next crawl; a failed build was never retried.
  Browsers prefer the live snapshot over the server render, so the headline, cards and list lagged behind
  the RSS feed, which is computed per request
- **What:** one source — `homeSnapshot()` serves `/api/home` (the home page render) and `/api/live`; checks run
  one at a time, a failed build is retried, the snapshot is rebuilt every minute; the frontend keeps its
  server render when a snapshot is older

### [Bug Fix] Endpoints compared only on the build both serve

- **Files:** `backend/src/web/queries.js`, `frontend/lib/format.js`, `frontend/components/Rollouts.js`,
  `frontend/app/rollouts/[channel]/[group]/page.js`, `backend/test/releases.test.js`, `backend/test/home.test.js`
- **Why:** a file one endpoint still served on the previous build counted as "differs" (16.0.20612.15140:
  "9 files differ" while OneCDN simply had not received most of them yet)
- **What:** `differentFiles` only for files both endpoints serve on this build; the rest is `notYetOn`
  ("not yet on onecdn" in the list, on the rollout page and next to Files); a build on one endpoint only is
  no longer `diverged`
