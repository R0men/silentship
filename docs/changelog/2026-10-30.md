### [Docs] Note: Word.LineFormat lost 8 documented properties in 16.0.20619

- **Files:** `frontend/content/notes/word-lineformat-removed-20619.md`
- **Why:** 16.0.20619.15190 removed `backgroundColor`, `pattern` and six arrowhead properties from `Word.LineFormat` on every Word platform, while Microsoft still documents them as WordApiDesktop 1.3 (production on Windows and Mac).
- **What:** a write-up with the removed properties, evidence from the host files, likely effects on add-ins, a search command and a feature check, and the rollout timeline on both endpoints. `builds` links it from the 16.0.20619.15190 rollout pages.
