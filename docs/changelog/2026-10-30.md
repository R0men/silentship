# 2026-10-30

### [Docs] Note: Word.LineFormat lost 8 documented properties in 16.0.20619

- **Files:** `frontend/content/notes/word-lineformat-removed-20619.md`
- **Why:** 16.0.20619.15190 removed `backgroundColor`, `pattern` and six arrowhead properties from `Word.LineFormat` on every Word platform, while Microsoft still documents them as WordApiDesktop 1.3 (production on Windows and Mac).
- **What:** a write-up with the removed properties, evidence from the host files, likely effects on add-ins, a search command and a feature check, and the rollout timeline on both endpoints. `builds` links it from the 16.0.20619.15190 rollout pages.

### [Feature] Severity follows the platforms where a requirement set is production

- **Files:** `backend/src/analysis/classify.js`, `backend/src/analysis/reclassify.js`, `backend/src/pipeline/run.js`, `backend/src/cli.js`, `TECH.md`, `docs/architecture/api-surface.md`
- **Why:** 16.0.20619 removed `Word.LineFormat` properties from WordApiDesktop 1.3, production on Windows and Mac only, and every Word file was High, iOS included.
- **What:** a GA change in a file for a platform where its set is not production drops one level (High → Medium, Medium → Low), with the reason in `apiDiffNote`; `WordApiDesktop`, `ExcelApiDesktop`, `WordApiHiddenDocument` → win32, mac; `WordApiOnline`, `ExcelApiOnline` → web. `reclassify` applies the rule to stored changes and has `--dry-run`.
