# 2026-10-15

### [Infra] Repository, CI and automatic deploys

- **Files:** `.github/workflows/ci.yml`, `.github/dependabot.yml`, `deploy/deploy.sh`, `deploy/silentship.service`, `.gitignore`, `.gitattributes`, `docs/SETUP.md`
- **Why:** the code only existed on a laptop and reached the server by hand; the server's copy was not a git checkout.
- **What:**
  - GitHub repository `R0men/silentship`, `main` = production; made public with MIT license, `SECURITY.md`, `CONTRIBUTING.md`.
  - CI on every push and PR: `npm ci` → `npm test` → `npm run build`; on `main` a `deploy` job (environment `production`, pinned host key).
  - The GitHub Actions key is limited on the server to a forced command, `deploy/deploy.sh`; the script deploys only commits on `origin/main`, runs `npm ci` only when the lockfile changed, waits for a running crawl before restarting (so the archive is never left with an `index.lock`) and checks that the API and the site respond.
  - A narrow sudoers rule lets the service user run only `systemctl restart silentship`.

### [Feature] SEO: sitemap.xml, robots.txt, canonical URLs, Open Graph

- **Files:** `frontend/app/sitemap.js`, `frontend/app/robots.js`, `frontend/app/opengraph-image.js`, `frontend/app/layout.js`, `frontend/app/page.js`, `frontend/app/rollouts/[channel]/[group]/page.js`, `frontend/app/privacy/page.js`, `frontend/lib/site.js`, `backend/src/web/queries.js`, `backend/src/web/server.js`, `docs/architecture/seo.md`
- **Why:** there was no sitemap or robots.txt (Googlebot got a 404 for `/robots.txt`), no canonical URLs and no Open Graph.
- **What:**
  - `/sitemap.xml` is generated per request from the new `GET /api/sitemap` (`sitemapGroups`): home, privacy and every rollout group with `lastmod`.
  - `/robots.txt` disallows `/api/`, `/confirm`, `/unsubscribe`, `/health`; absolute `Sitemap:`.
  - `metadataBase` from `PUBLIC_URL`; `pageMeta()` builds canonical, RSS alternate, Open Graph and Twitter for every page; JSON-LD `WebSite` on the home page; a 1200×630 OG image; a missing rollout page is `noindex`.
