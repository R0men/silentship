Between [16.0.20619](/notes/word-lineformat-removed-20619), which removed eight Word properties, and [16.0.20710](/notes/excel-allowtexttooverflow-20710), Microsoft shipped two more builds of Office.js. Neither changed a documented API. Here is what they did change. On beta, there are a few Excel names that are probably on their way.

## 16.0.20626: Office's own ribbon code

| | |
|---|---|
| Production | first seen 2 Nov, 22:50 UTC; on every sampled edge by 6 Nov, 08:50 UTC |
| Changes | 7, all in undocumented members |

- `OfficeCore.RibbonButton` gained `actionId` and `icon`. Its `set()` and `toJSON()` changed with them. That's the side effect described in [the 16.0.20710 note](/notes/excel-allowtexttooverflow-20710), and silentship now marks it that way.
- `Excel.CustomFunctionProxy` (`setCustomFunctionAssociation`, `setCustomFunctionInvoker`) got a new implementation in three Excel host files. It is internal plumbing, not the documented `CustomFunctions` API. If your custom functions behave differently after this build, this is the place to start looking.

## 16.0.20702: an internal enum goes away

| | |
|---|---|
| Production | first seen 9 Nov, 20:20 UTC; on every sampled edge by 17 Nov, 06:50 UTC |
| Changes | 4 on production, 10 on beta, all in undocumented members |

On production:

- `Excel.ActionCellValueType` was removed. On beta, the same build kept it but replaced the value `javaScriptReference` with `javaScriptAction`. The enum was never documented, so nothing an add-in should use broke.
- `OfficeExtension.MarkOfAi`, a new undocumented enum, appeared in all 21 host files.
- `OfficeCore.DimeApi.launch` and `Excel.CustomFunctionProxy` got a new implementation again.

It took the longest of the recent builds to roll out, a little over seven days. [16.0.20710](/notes/excel-allowtexttooverflow-20710) started appearing before it had finished.

## What beta 16.0.20702 shows for Excel

The beta build adds a few Excel members that are in neither `@types/office-js` nor `@types/office-js-preview` yet:

| Member | What it is |
|---|---|
| `Excel.PivotTable.lastRefreshed` | a property. The documented `lastRefreshed` on `Excel.LinkedEntityDataDomain` (ExcelApi 1.19) is a `Date`, so this one is probably the time of the last refresh too |
| `Excel.Workbook.getPromptChangeIntents`, `upsertPromptChangeIntent` | two methods with no public explanation yet |
| `Excel.Dashboard.activate` | a method on a type that isn't documented at all |
| `Excel.UserActivity.location` | a property, and six new `Excel.UserActivityType` values: `comment`, `note`, `hyperlink`, `definedName`, `deleteDefinedName`, `drawingElement` |

Don't build on them: undocumented members change or disappear without notice, as `ActionCellValueType` just did. If one of them matters to your add-in, watch for it in the preview docs.
